# NOVOLAMPA Conventions

- Reuse existing blocks when the structure matches, even if the original class name is tied to another page.
- Search the project before adding new code: styles, includes, functions, and commented imports may already cover the task.
- Keep the bundle lean. Prefer existing markup, styles, and scripts over new modules.
- Ask or push back when implementation choices are uncertain or the provided direction may miss an important case.
